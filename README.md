# Pokédex – Trabalho Final de Front-End II (Unilavras)

## Tema
Pokédex: listagem de Pokémon e página de detalhes de cada um.

## API utilizada
PokéAPI – https://pokeapi.co/api/v2/pokemon (gratuita, sem chave)
- Listagem: `GET /pokemon?limit=20&offset=0`
- Detalhes: `GET /pokemon/{id}`

## Como executar
1. Extraia o arquivo `.zip`.
2. Abra `index.html` no navegador (ou use a extensão Live Server do VS Code).
3. Clique em "Ver detalhes" em qualquer card; use "Voltar à listagem" para retornar.
É necessária conexão com a internet.

## Estrutura
- `index.html`, `style.css`, `script.js` – Rota 1 (listagem)
- `paginaInfo/` – Rota 2 (detalhes)
